# ArknightsTimeline v3.6.0 更新公告

v3.6.0 适配 2026-09 游戏更新后的敌人、属性、Buff 与角色内存布局，并新增严格同帧的敌人路线、目标点和检查点读取能力。

## 敌人实时路径

- 敌人表在“精确坐标”后新增五列：意图终点、当前路线、下一路点、下一检查点、检查点倒计时。
- 当前路线会将运行时 `Route` 与关卡主路线、额外路线匹配，显示为“主#1（A1→F10）”“额外#1（A1→F10）”；无法安全匹配的动态路线明确显示为运行时路线，不猜测静态编号。
- 意图终点读取当前 `RouteData.endPosition`，目标为蓝门或友方目标格时显示例如“F10（友方目标）”。
- 下一路点读取运行时 `DirectionCursor.m_nextGrid`；下一检查点读取本帧 `checkpoints[cursorIndex]`，支持移动、等待、传送、警戒、巡逻和 BossRush 等类型。
- 等待检查点统一显示秒数和逻辑帧，例如“2.37秒 / 71帧”；移动与事件条件不伪造精确倒计时。

## memsrv v5 同帧快照

- 设备侧内存服务升级为 `memsrv v5`，新增带 `fixedFrameCount` 守卫的一次性动态事务。
- `checkpoints[cursorIndex]` 在设备侧使用本帧 CursorIndex 动态解引用，所有活敌人仍在一次事务中完成，不进行逐敌人主机往返。
- 每个敌人的 Cursor、Route、RouteData、Checkpoint 和 CheckpointData 链在同一事务中读取两遍并比较身份；帧号、对象身份或内容发生变化时拒绝发布。
- 路径读取失败时 UI 和 WebSocket 会立即撤下旧路线并显示“同步重试”，不会用上一帧路径冒充当前帧。
- memsrv 自动部署改用 SHA-256 校验，避免协议升级后因二进制尺寸相同而遗漏覆盖设备旧版本。
- RNG 与操作记录的独立内存通道同步使用 v5 协议。

## 游戏更新适配

- 更新 `Enemy` 新增路线终点字段后整体右移的动作、技能、数据与 Wrapper 偏移。
- 更新 `Attributes` 新增异常抗性字段后的原始/最终属性数组和异常组合管理器偏移。
- 更新 `Buff`、`BuffData` 新增异常抗性和剩余时间键后的全部运行时字段。
- 更新 `Character` 卡片 UID 与角色数据指针，并将属性头读取长度统一改为结构定义。
- 扩展自动偏移生成器至 36 个关键结构；`--check` 会拒绝与当前 `dump.cs` 不一致的陈旧偏移文件。

## 界面与外部接口

- 新增 `enemy_pathing` WebSocket 主题，默认 30Hz、最高 60Hz，输出结构化帧号、路线、目标格、检查点和倒计时。
- `enemies.updated` 同时携带路径摘要；所有公开字段使用白名单，不包含 Enemy、Cursor、Route 或 Checkpoint 地址。
- 新路径列会为旧用户执行一次可见性和顺序迁移，之后继续尊重用户自己的隐藏和拖动设置。
- 主界面“选择 ADB”左侧新增“新手教程”，应用内可直接阅读 ADB、自动寻址、扫描、导出和故障排查说明。
- 新手教程作为资源内嵌到正式版和测试版单文件程序中。

## 稳定性与验收

- 修复路径失效通知可能受 WebSocket 主题限流影响、导致客户端短暂保留旧路线的问题。
- 修复 UI 只清空单元格但保留旧路径对象，调整列设置时可能重新显示旧路线的问题。
- 修复 IL2CPP 数组 `max_length` 被错误按 64 位读取、将填充数据并入长度的问题。
- 修复仅因 trace cursor 对象存在便误报正在偏航的问题。
- 直接相关测试覆盖敌人读取、角色读取、v5 协议、路径同帧校验、桌面表格、WebSocket、RNG 与操作记录；未运行独立的 `Ark_emulator` 测试模块。
